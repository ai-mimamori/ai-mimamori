# AIみまもり

事業会社の非エンジニアが AI に作らせたツールを、**各自の PC の中だけ**で検査します。ウイルス対策やセキュリティ SaaS が見逃しやすい「合鍵の直書き」「確認しない実行」「共有への混入」を、専門用語を避けて日本語で出します。

コードは公開して配ってかまいません。検査そのものはクラウドに出さず、`127.0.0.1`（自分の PC）にだけ接続します。他の PC やインターネットからは届きません。

## 使い方

1. [Node.js LTS](https://nodejs.org) を入れる（最初の 1 回だけ。その後はオフラインで動きます）
2. このフォルダを自分の PC にコピーする（USB でも ZIP でも可）
3. `スタート.bat` をダブルクリックする
4. 開いた画面で「デモを検査する」

詳しくは `使い方.txt` を見てください。

## このアプリが外から操作されない理由

- 待ち受けは `127.0.0.1` だけ（社内 LAN に公開しない）
- ブラウザの画面は、この PC で起動したときだけ通る
- 検査対象のプログラムは実行しない。読むだけ
- 起動後にネットへ問い合わせない。追加の npm パッケージもない

## 検証している仮説

非エンジニアでも、フォルダを指定するだけで「危ない理由」と「今やること」が分かれば、影で増えた AI 成果物の危険に気づける。
