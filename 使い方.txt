AIみまもり 使い方
================

これは「各自のPCの中」で動かす検査です。
コードは公開して配ってよいですが、動かすときはインターネットに出しません。
社内の他のPCから操作することもできません。

1. 最初の1回だけ
   Node.js の LTS を https://nodejs.org から入れる
   （会社PCで入れられないときは、IT部門に「ローカル開発ランタイム」として依頼する）

2. このフォルダを、使う人のPCへコピーする
   GitHub から Download ZIP でも、USB に入れて渡してもよい
   コピーしたあとは、ネットを切ったまま使ってよい

3. 「スタート.bat」をダブルクリックする
   黒い窓が開いたら、ブラウザが http://127.0.0.1:3780 を開く
   これは「自分のPC」という意味の住所で、外からは届かない

4. 「デモを検査する」を押して、動きを確認する

5. 自分のフォルダを見るとき
   エクスプローラーでフォルダを右クリック → パスのコピー → 貼り付け → 検査する

止めるとき
  黒い窓を閉じる

やってはいけないこと
  スタートしたまま、他人に画面を操作させない
  合鍵の入った検査結果をチャットに貼らない
  このアプリを社内サーバーに置いて皆で共有しない
  （皆で使うなら、各自のPCにコピーして各自で起動する）
